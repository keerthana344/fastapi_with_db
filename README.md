# FastAPI with DB

This is the backend for the Chat GPT frontend application.

## Persistence

To keep the backend running even after closing the terminal or Antigravity:

1. **Start**: Double-click [start_persistent.vbs](file:///c:/Users/student/Documents/fastapi_with_db/start_persistent.vbs) or run it from a terminal. This will start the backend in a hidden, detached process.
2. **Stop**: Run [stop_persistent.ps1](file:///c:/Users/student/Documents/fastapi_with_db/stop_persistent.ps1) in a PowerShell terminal to kill the background process.
